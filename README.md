# 바톤(BATON): 발달장애인 돌봄 인계 플랫폼

> 돌볼 수 없게 되는 날, 돌봄으로 이어 드립니다.

「2026 사회보장 데이터를 활용한 AI 혁신 아이디어 경진대회」 출품작입니다.
부모가 더 이상 돌볼 수 없게 된 발달장애인이 시설마다 전화를 돌리며 거절당하지 않도록, **돌봄 이력서 한 장으로 시설과 주민센터에 한 번에 의뢰**하고, 시설의 회신과 시군구의 검토·위탁을 한 흐름으로 잇습니다.

## 무엇이 들어 있나

| 폴더 | 내용 |
|---|---|
| `web_demo/` | 시연용 웹 서비스. `index.html` 을 브라우저로 열면 바로 동작합니다(서버 불필요). |
| `src/` | 공공데이터 수집·전처리·검증·시각화 코드(Python) |
| `data/processed/` | 전처리 결과(시설 1,524곳·주간이용 855곳, 시군구 패널, 사업안내 규칙 등) |
| `data/api/` | 한국사회보장정보원 사회복지시설정보 OpenAPI 수집 결과(2026-11-06, 시설 2,384곳) |
| `notebooks/` | 결과가 들어 있는 탐색 노트북 |
| `outputs/figures/` | 그래프 10종 |

## 화면 구성(역할별)

| 역할 | 할 수 있는 일 |
|---|---|
| 발달장애인 보호자 | 메모를 AI가 돌봄 이력서로 정리 → 사는 곳의 돌봄 경로와 추천 시설 확인 → 시설과 주민센터에 동시 의뢰 → 진행 상황 확인 |
| 시설 담당자 | 들어온 의뢰와 이력서 확인, AI 입소 상담 질문 생성, 수용 가능·대기·거절 회신(거절 사유 AI 분류), 우리 시설이 대응할 수 있는 돌봄 등록 |
| 담당 공무원 | 의뢰별 자격 검토와 위탁 결정, 관할 시군구 현황(2026 API 현행화), AI 주간 보고서 초안, 돌봄 공백 현황, 보조금 설계 |

AI 기능(이력서 정리, 상담 질문, 거절 사유 분류, 보고서 초안)은 생성형 AI가 연결된 환경에서 동작하고, 연결되지 않으면 같은 화면에서 규칙 기반 결과로 대신합니다. 수치는 모두 코드가 계산하고, AI는 문장 정리와 분류만 맡습니다.

| 데이터 | 제공 | 활용 |

| 2025년 국민기초생활보장사업안내 | 보건복지부 | 보장시설·위탁·급여관리 규칙(쪽수 표기) |
| 시군구별 장애정도별 등록장애인 수 | 보건복지부 등록장애인 현황 | 시군구별 심한 장애 인구(돌봄 수요) |
| 장애인거주시설 현황(2020~2025) | 보건복지부 통계 | 입소인원 추이 |

원자료 파일(PDF·xlsx 등)은 저장소에 넣지 않았습니다. 각 기관에서 받아 이 폴더의 상위 폴더에 두면 `python src/run_all.py` 로 같은 결과를 다시 만들 수 있습니다.
개인정보 보호를 위해 API 결과의 대표자 이름 열과, 담당자 연락처가 들어 있는 구인 공고 원문은 저장소에서 뺐습니다(집계 결과만 포함). 인증키는 코드와 결과 어디에도 들어 있지 않습니다.

시연 화면의 부모 메모와 인물은 가상 예시입니다.

# 데이터 파이프라인 실행 방법

발달장애인 돌봄 인계 플랫폼 **바톤**에 쓰는 공공데이터를 원자료에서 직접 전처리하고, 검증하고, 시각화하는 VS Code 프로젝트입니다.
「2026 사회보장 데이터를 활용한 AI 혁신 아이디어 경진대회」 제출용입니다.

## 1. 처음 한 번 준비 (Windows, VS Code)

1. VS Code에서 **파일 → 폴더 열기**로 이 `baton_project` 폴더를 엽니다.
   - `.vscode` 폴더에 실행 버튼(F5 목록)과 작업 메뉴가 들어 있습니다.
2. 오른쪽 아래에 추천 확장(Python, Jupyter, Rainbow CSV, PDF 미리보기) 설치 안내가 뜨면 설치합니다.
3. **터미널 → 작업 실행 → `처음 한 번: 가상환경 만들고 패키지 설치`** 를 누릅니다.
   - 직접 입력하려면 VS Code 터미널(PowerShell)에서:
     ```powershell
     python -m venv .venv
     .\.venv\Scripts\python -m pip install -r requirements.txt
     ```
4. 오른쪽 아래 Python 인터프리터를 `.venv` 로 고릅니다.

원자료(PDF·CSV·xlsx·zip·docx)는 **이 폴더의 바로 위 폴더**(`바탕화면\사회보장`)에서 자동으로 찾습니다.
다른 곳에 두었다면 환경변수 `BATON_RAW_DIR` 로 위치를 알려 주세요.

## 2. 실행

| 하고 싶은 일 | 방법 |
|---|---|
| 전처리 + 시각화 + 노트북 전부 | `Ctrl+Shift+B` (기본 빌드 작업) 또는 실행 및 디버그(F5) → **1. 전체 실행** |

## 3. OpenAPI 인증키

`src/api_key.py` 가 아래 순서로 키를 찾습니다. 키는 화면에 앞뒤 4자리만 보이고, 결과 파일에는 저장하지 않습니다.

1. 환경변수 `DATA_GO_KR_SERVICE_KEY`
2. 이 폴더의 `.env` 파일 (`.env.example` 을 복사해 키 입력)
3. 원자료 폴더의 「OpenAPI활용가이드_16.한국사회보장정보원(사회복지시설정보)_key.docx」 첫 줄 `내 key: …`

> 그 docx 파일에는 키가 그대로 적혀 있으니, 공모전 제출물이나 팀 공유 폴더에 올릴 때는 키 줄을 지우세요.

주소는 고도화된 `https://apis.data.go.kr/B554287/sclWlfrFcltInfoInqirService2` 이고, 오퍼레이션 이름 끝에 `2` 가 붙습니다(예: `getFcltListInfoInqire2`). 한국사회보장정보원 공지(2026.9.4)대로 기존 주소는 2026.9.11 이후 쓸 수 없어, 가이드 v2.5(Service1 기준)의 주소를 그대로 쓰면 `NO_OPENAPI_SERVICE_ERROR` 가 납니다. 구인정보 조회에서 결과코드 40(`NO DATA FOUND`)은 오류가 아니라 '현재 공고 없음'입니다.
받은 응답은 `data/api/raw/` 에 캐시되어, 중간에 끊겨도 다시 실행하면 이어서 받습니다(개발계정 하루 10,000회 한도).

## 6. 해석할 때 주의

- 시설의 시군구는 **소관** 시군구입니다. 서울 소관 시설 12곳은 실제로 경기도 등에 있습니다(`소재지시도` 열).
- 빈자리(정원−현원)는 즉시 입소 가능 여부가 아닙니다.
- 수요 지표(심한 장애 등록장애인)는 모든 장애유형을 포함합니다.
- 2025년 거주시설 추이 값은 제공 xlsx에 적힌 출처(2026 일람표) 기준이며, 원문 PDF로는 확인하지 않았습니다.

연결은 같은 시도·같은 돌봄 단계 안에서 ① 정규화한 시설명이 같거나 ② 짧은 이름이 긴 이름에 포함될 때(짧은 쪽 4글자 이상 또는 길이 비율 0.75 이상)만 1:1로 합니다. 이름으로 연결되지 않은 시설은 신설·폐지·명칭 변경 '후보'이며 확정이 아닙니다. 2026 API의 `전남광주통합특별시` 는 구 이름(동·서·남·북·광산구)으로 광주와 전남을 나눴습니다.
